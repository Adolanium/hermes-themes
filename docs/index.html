Install a pack in a minute

  1. Install

    In Hermes Desktop, open Capabilities → Plugins, click Install from Git and paste a pack's address. Or use the terminal:

    • Turn it on

      The pack appears in Capabilities → Plugins. Flip its Desktop switch on. Packs installed from Git start turned off.

    • Pick a god

      Type /skin and a god's name in the message box, like /skin thoth. The packs install side by side, and no two gods share a name.
